# 🌐 Language Translation Tool

A simple and user-friendly web application that translates text between different languages.

## 🚀 Features

- Translate text between supported languages
- Select source language
- Select target language
- Simple and clean user interface
- Display translated text clearly
- Responsive design for laptop and mobile
- Copy translated text

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- React
- TypeScript
- Tailwind CSS

## 🌍 Supported Languages

- English
- Telugu
- Hindi

## 📌 Project Description

This Language Translation Tool was developed as part of my Artificial Intelligence internship at CodeAlpha.

The application allows users to enter text, select the source and target languages, and get the translated result through the translation service.
